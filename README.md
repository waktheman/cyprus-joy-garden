# Cyprus Joy Garden — website preview

A single-file, self-contained preview of the Cyprus Joy Garden marketing site.
Open the live version here:

**https://waktheman.github.io/cyprus-joy-garden/**

## What this is

A design and content preview built as one static HTML file — no build step, no
dependencies to install. It covers the full site: home, services (plus a page per
service), portfolio with before/after comparisons, about, contact and the journal.

- Momentum scrolling via [Lenis](https://github.com/darkroomengineering/lenis), bundled inline
- Scroll-triggered reveals (fade + slide-up, staggered children)
- Full light and dark themes, driven by the visitor's system preference
- Responsive from 320px up
- Respects `prefers-reduced-motion` — all motion is disabled if the visitor asks for it

## Before this becomes the real site

The content is realistic placeholder material. Three things **must** be replaced:

1. **Review figures.** "4.9 from 127 Google Reviews" and the four review quotes are
   invented. Publishing invented review data misrepresents the business to customers
   and breaches Google's structured-data policy. Substitute the real Google Business
   Profile figures, or remove the block.
2. **Team photographs.** The four portraits are stock photographs of real people who
   do not work for the company. Replace them with photographs of actual staff.
3. **Before/after pairs.** Each pair is two thematically matched stock photographs, not
   the same site photographed twice. Replace with genuine project pairs.

Prices, the phone number, email, address and licence number are also placeholders.

Photography is from [Unsplash](https://unsplash.com) under their licence.
The page is marked `noindex` so it stays out of search results while it is a preview.
